Video plays sound but no picture

Last updated: 3 November 2026

Many videos in GeoGallery, including every 360° video, are stored in the HEVC (H.265) format, as the camera recorded them. If your browser cannot decode HEVC, the video stays black or empty while its sound plays. GeoGallery then shows a message with a link to this page.

There is nothing wrong with the file. Your browser needs a way to decode HEVC.

Which browsers can play HEVC

  • Safari on macOS, iPhone and iPad: yes.
  • Chrome, Edge, Brave and other Chromium browsers on Windows and macOS: yes, on most graphics hardware from the last several years.
  • Chrome, Brave, Chromium and Edge on Linux: only if your graphics card decodes HEVC and the browser can use it (see below). These browsers have no software decoder for HEVC on Linux.
  • Firefox on Linux (version 137 or newer): yes. It decodes HEVC through the system's FFmpeg, on the graphics card when it can and on the processor otherwise.
  • Firefox on Windows: on graphics hardware that decodes HEVC. On other computers, use Chrome or Edge.

Quickest fix on Linux: use Firefox

Open GeoGallery in Firefox 137 or newer. To check that it can decode HEVC, open about:support, go to the Media section and look for HEVC under codec support.

360° videos are 5760 × 2880 pixels. Without the graphics card's help, playing them takes a fast processor and may stutter on older computers.

Chrome, Brave or Chromium on Linux

1. Check what the browser can decode

Open brave://gpu in Brave, chrome://gpu in Chrome or Chromium, or edge://gpu in Edge. Under Video Acceleration Information, look for a Decode hevc main line.

  • If it is there and its maximum size is at least 5760x2880, the browser can play every video. Reload GeoGallery.
  • If it is missing, or the maximum is smaller, continue with the steps below.

2. Turn on graphics acceleration

In the browser's settings, open System and turn on Use graphics acceleration when available. Restart the browser.

3. Install the video driver for your graphics card

The browser decodes video through VA-API. Install the driver that matches your graphics card:

  • Intel (6th-generation Core, "Skylake", or newer): 
    sudo apt install intel-media-va-driver
  • AMD: 
    sudo apt install mesa-va-drivers
    On Fedora, the standard Mesa drivers have HEVC turned off. Install mesa-va-drivers-freeworld from RPM Fusion instead.
  • NVIDIA (proprietary driver): install nvidia-vaapi-driver, version 0.0.18 or newer for correct HEVC. Chromium support for it is experimental and needs extra settings when you start the browser: 
    LIBVA_DRIVER_NAME=nvidia brave-browser \
  --enable-features=AcceleratedVideoDecodeLinuxGL,VaapiOnNvidiaGPUs
    Use google-chrome or chromium instead of brave-browser for those browsers. On Wayland, also add --ozone-platform=wayland.

To check that the driver can decode HEVC, run:

sudo apt install vainfo
vainfo | grep -i hevc

The output should contain VAProfileHEVCMain : VAEntrypointVLD. If it does not, your graphics card cannot decode HEVC, and the browser cannot either. Use Firefox instead.

4. Restart the browser and check again

Quit every browser window, start the browser again and repeat step 1. Some setups also need the --enable-features=AcceleratedVideoDecodeLinuxGL start-up option shown above. These options are experimental and their names can change between browser versions.

If Decode hevc main appears but its maximum is below 5760x2880, normal videos will play but 360° videos will not. Use Firefox for those.
